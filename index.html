What developers actually adopt in the AI era

The question
If you sold developer tools, where would you bet — which AI tools are crossing from hype into daily use, and among which developers?
The approach
Reshape the 90K-respondent Stack Overflow Developer Survey, then segment AI-tool adoption by role, experience, and company size — testing where the gaps are statistically real, not noise.

PROJECT 02 · EXPERIMENTATIONdecisive

Ship it or kill it: an A/B test post-mortem

The question
A team ran an experiment on a new checkout flow. The topline looks up — but should it actually ship?
The approach
Validate the randomization (sample-ratio mismatch), measure lift with two-proportion Z-tests and confidence intervals, run a power and sample-size check, and rule out peeking.
The decision it drives
A defensible ship / no-ship verdict with the statistics behind it — plus exactly what would have to change to flip the call.
Stack
Python (pandas, statsmodels), SQL · public e-commerce A/B dataset
status: to build view code → read notebook →

Why subscribers leave — and who to save first

The question
With a fixed retention budget, which customers should we spend it on to save the most revenue?
The approach
